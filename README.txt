TECH ASSISTÊNCIA — SISTEMA WEB
================================

Como testar:
1. Extraia o ZIP.
2. Abra index.html no navegador.
3. Cadastre clientes antes de criar OS.
4. Em Configurações, informe o link do Google e WhatsApp.
5. O sistema usa localStorage para testes e protótipo.

Estrutura:
index.html
assets/style.css
assets/app.js
pages/clientes.html
pages/os.html
pages/financeiro.html
pages/consulta.html
pages/configuracoes.html

IMPORTANTE:
Esta versão é um protótipo funcional front-end. Os dados ficam no navegador.
Para uso online com vários celulares/computadores, será necessário um backend/banco
de dados e autenticação real. O envio via WhatsApp abre o WhatsApp com a mensagem
da OS pronta para envio.
